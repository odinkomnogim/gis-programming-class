# Задание 5. Геометрия векторных объектов: буферизация и поиск пересечений
Работа осуществляется в редакторе Python консоли QGIS.
<br>Задача – просмотреть некоторые возможные операции с геометрией объектов. Сделаем это на примере буферизации точек по одному из полей атрибутивной таблицы и определения пересечения двух полигональных слоёв.
<br>Процесс работы может (но не обязан) выглядеть следующим образом:
-	Открыть слой станций (они репрезентированы точечными объектами)
-	Создать пустой полигональный временный векторный слой QgsVectorLayer('Polygon?crs=EPSG:3857', название, память) и определить провайдер его данных (dataProvider)
-	С помощью провайдера перенести (addAttributes) поля атрибутивной таблицы слоя станций (fields) в новый слой, после чего обновить его атрибутивную таблицу (updateFields)
-	Найдя в таблице «Задание_5.xlsx» свою задачу, получить доступ к объектам слоя станций (getFeatures) и буферизовать каждый из них (buffer). Данная функция буферизации принимает 2 аргумента: радиус и число сегментов (насколько сглаженной получится геометрия, 8 более чем достаточно)
-	Для каждой из станций получить значения атрибутов (attributes), создать новый объект (QgsFeature), задать ему геометрию определённого ранее буфера (setGeometry) и значения атрибутов (setAttributes), а также добавить объекты с помощью провайдера (addFeatures([объект])) и обновить пространственный охват слоя (updateExtents)
-	Добавить слой с буферизацией на карту (QgsProject.instance().addMapLayer)
-	Для объекта в полученном слое и для объекта в слое районов (цикл в цикле) проверить пересечение геометрий (intersects) и соблюдение объектами условий из Вашего задания
-	Выделить объект слоя районов на карте по его id (select)
